# Security

Просвет выполняет привилегированные сетевые операции в Windows. Поэтому модель безопасности проекта строже, чем у обычного Flutter GUI.

## Trust boundaries

Приложение состоит из нескольких частей:

- Flutter GUI и controller;
- Windows backend, который вызывает системные команды;
- `winws2.exe` / WinDivert из закреплённого релиза zapret2;
- локальный Telegram proxy;
- NRPT-правила Windows для выбранных Smart DNS-доменов.

Просвет не устанавливает собственный root CA и не расшифровывает HTTPS.

## Защита lifecycle

- Системные mutations сериализованы и не должны выполняться параллельно.
- `winws2.exe` привязан к Windows Job Object с kill-on-close.
- Разрешён один системный экземпляр GUI.
- NRPT-правила Просвета помечаются отдельным comment и очищаются при stop, следующем старте после сбоя и uninstall.
- Installer проходит автоматический install/uninstall smoke-test.

## Supply chain

- Версия zapret2 закреплена в `tools/fetch-engine.ps1`.
- Загруженный архив zapret2 проверяется по ожидаемому SHA-256 до распаковки.
- GitHub Actions dependencies закреплены на commit SHA.
- Релиз создаётся только если git tag совпадает с версией в `pubspec.yaml`.
- Setup.exe и portable ZIP публикуются вместе с `SHA256SUMS.txt`.

Бинарники 0.1.0 пока не подписаны коммерческим Authenticode-сертификатом. Проверка SHA-256 подтверждает целостность скачанного артефакта относительно опубликованного release asset, но не заменяет подпись издателя.

## Что не является границей безопасности

Просвет не является sandbox, антивирусом или системой аутентификации. Пользователь с правами администратора уже может изменять системные сетевые настройки и файлы приложения.

## Сообщить об уязвимости

Не публикуйте рабочий exploit, секреты или чувствительные данные в обычном issue.

Сначала свяжитесь с владельцем репозитория через GitHub и сообщите минимальные сведения: затронутая версия, компонент, влияние и безопасные шаги воспроизведения. Обычные функциональные баги можно отправлять через Issues.
