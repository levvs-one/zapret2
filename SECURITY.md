# Политика безопасности

Просвет меняет системное сетевое состояние Windows и запускается с повышенными правами. Поэтому целостность релиза, корректный cleanup и предсказуемый lifecycle считаются частью безопасности продукта, а не только эксплуатационными деталями.

## Поддерживаемые версии

| Версия | Статус |
| --- | --- |
| 0.2.x | поддерживается |
| 0.1.x | только историческая совместимость |

Исправления безопасности публикуются в новой patch/minor-версии. Уже опубликованные бинарники под существующим номером версии не заменяются.

## Что входит в модель безопасности

Release pipeline проверяет:

- фиксированную версию zapret2;
- SHA-256 скачанного engine archive;
- форматирование, analyzer и тесты;
- сформированные аргументы через parser самого zapret2;
- Windows release build;
- установку и удаление Setup.exe;
- наличие engine-файлов в установленной сборке;
- публикацию Setup, portable ZIP и `SHA256SUMS.txt`.

GitHub Actions в workflow закрепляются по commit SHA.

## Системные инварианты

Просвет проектируется так, чтобы:

1. системные изменения не выполнялись параллельно;
2. завершённый `stop()` означал завершённый cleanup;
3. дочерний `winws2.exe` не переживал приложение штатно;
4. собственные NRPT-правила удалялись после выключения;
5. leftovers после crash удалялись при следующем запуске;
6. только один экземпляр приложения управлял системным состоянием;
7. uninstall удалял собственный autostart, NRPT и локальные данные.

## Чего Просвет не делает

Просвет не является:

- антивирусом;
- sandbox;
- VPN;
- TLS interception proxy;
- системой анонимизации;
- средством сокрытия публичного IP;
- механизмом цифровой подписи собственных бинарников.

Приложение не устанавливает собственный root CA и не расшифровывает HTTPS.

## Проверка релиза

Используйте только GitHub Releases этого репозитория.

Для проверки Setup:

```powershell
Get-FileHash .\Prosvet-*-Setup.exe -Algorithm SHA256
```

Для portable:

```powershell
Get-FileHash .\Prosvet-*-windows-x64.zip -Algorithm SHA256
```

Сравните значение со строкой из `SHA256SUMS.txt` соответствующего релиза.

> Текущие бинарники не подписаны коммерческим Authenticode-сертификатом. Поэтому SmartScreen может показывать предупреждение о неизвестном издателе.

## Сообщить об уязвимости

Не публикуйте рабочий exploit, секреты, токены или чувствительные сетевые данные в обычном issue.

В первичном сообщении достаточно указать:

- версию Просвета;
- версию Windows;
- затронутый компонент;
- ожидаемое и фактическое поведение;
- минимальные шаги воспроизведения;
- влияет ли проблема на privilege boundary, cleanup, release integrity или сетевое состояние.

Если воспроизведение требует чувствительных данных, сначала свяжитесь с владельцем репозитория через GitHub и запросите приватный канал.

Для обычных ошибок используйте **[Issue templates](https://github.com/levvs-one/zapret2/issues/new/choose)**.

## Особенно важные классы проблем

Особенно полезны отчёты о:

- выполнении неожиданных команд или аргументов;
- обходе single-instance/lifecycle serialization;
- оставшихся WinDivert/NRPT состояниях после OFF или uninstall;
- подмене/непроверенной загрузке engine;
- публикации release artifact, который не прошёл ожидаемый pipeline;
- утечке proxy secret или локальных данных;
- небезопасной обработке внешних URL/путей.
