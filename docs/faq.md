# FAQ

## Это VPN?

Нет.

Просвет не создаёт общий VPN-туннель для всего интернет-трафика.

Для разных сервисов используются разные механизмы:

- zapret2 / WinDivert для DPI;
- Windows NRPT + Smart DNS для выбранных доменов;
- локальный proxy для Telegram Desktop.

Остальной трафик идёт обычным маршрутом.

## Просвет скрывает мой IP?

Не как общий VPN.

DPI-механизм не меняет ваш публичный IP. Smart DNS может менять маршрут только для доменов, которые обслуживает провайдер Smart DNS.

## Чем Просвет отличается от zapret2?

zapret2 — низкоуровневый anti-DPI engine.

Просвет — Windows-приложение, которое использует zapret2 для части сервисов, а также добавляет Smart DNS, Telegram proxy, UI, lifecycle, installer, cleanup, health checks и память стратегии.

Подробнее: [Просвет vs zapret2](prosvet-vs-zapret2.md).

## Почему нужны права администратора?

WinDivert работает на системном уровне, а NRPT — системная функция Windows.

Без elevation эти механизмы нельзя корректно применить.

## Есть телеметрия?

Нет.

Просвет не требует аккаунта и не отправляет разработчику настройки или usage analytics.

Подробнее: [PRIVACY.md](../PRIVACY.md).

## Просвет меняет HTTPS или устанавливает сертификат?

Нет.

Он не устанавливает собственный root CA и не расшифровывает HTTPS-трафик.

## Почему антивирус может ругаться?

WinDivert и программы, которые меняют обработку сетевого трафика, нередко вызывают эвристические предупреждения.

Не отключайте защиту вслепую. Используйте только официальный GitHub Release и при необходимости сверяйте SHA-256.

## Почему SmartScreen пишет «неизвестный издатель»?

Потому что текущие бинарники не подписаны коммерческим Authenticode-сертификатом.

Это ограничение релиза, а не отдельная ошибка Windows.

## Почему ChatGPT / Gemini всё ещё пишет про страну?

Сетевой маршрут — не единственный сигнал.

Сервис может учитывать:

- регион аккаунта;
- платёжный профиль;
- номер телефона;
- историю аккаунта;
- собственные anti-abuse проверки.

Просвет не меняет эти данные.

## Почему браузер не использует Smart DNS?

Проверьте Secure DNS / DNS-over-HTTPS.

Если браузер отправляет DNS-запросы напрямую своему DoH-провайдеру, Windows NRPT может не участвовать.

## Работает вместе с VPN?

Иногда да, иногда нет.

VPN может:

- менять DNS;
- ставить собственный packet filter;
- менять маршруты;
- конфликтовать с WinDivert.

Если есть проблемы, сначала проверьте Просвет без второго VPN/zapret-клиента.

## Можно добавить другой сервис?

Да, но механизм зависит от причины блокировки.

Откройте [Issue](https://github.com/levvs-one/zapret2/issues/new/choose) с названием сервиса и описанием того, как именно он не работает.

## Почему нет сотен настроек zapret2?

Потому что Просвет — не GUI для всех опций zapret2.

Цель — предоставить небольшой устойчивый продукт для известных сценариев.

Для полного контроля используйте zapret2 напрямую.

## Где лежат настройки?

`%LOCALAPPDATA%\Prosvet`

Там находятся:

- `settings.json`;
- память стратегий;
- `prosvet.log`.

## Как полностью удалить Просвет?

Используйте стандартный Windows uninstall.

Подробности: [Установка и удаление](getting-started.md#удаление).
