# Диагностика

Эта страница — первый маршрут, если Просвет включён, но сервис работает не так, как ожидалось.

## Быстрая проверка

Перед глубокой диагностикой:

1. убедитесь, что нужный сервис включён в Просвете;
2. выключите второй VPN/zapret/WinDivert-клиент;
3. для Smart DNS временно отключите Secure DNS / DoH в браузере;
4. нажмите **Настройки → Сеть → Проверить сервисы**;
5. перезапустите Просвет, если до этого он или Windows завершились аварийно.

## Сервис отмечен красным

Откройте **Настройки → Сеть → Проверить сервисы**.

Для DPI-сервисов повторная проверка позволяет движку использовать следующий подготовленный вариант стратегии. Если проблема стабильна, создайте DPI strategy report и укажите провайдера/тип сети.

## ChatGPT / Gemini / Claude всё ещё пишет про страну

Smart DNS меняет сетевой маршрут только для выбранных доменов.

Он не меняет:

- регион аккаунта;
- платёжный профиль;
- номер телефона;
- историю аккаунта;
- внутренние anti-abuse сигналы сервиса.

Поэтому сетевой доступ и доступность конкретного аккаунта — разные вещи.

## Сайт вообще не открывается через Smart DNS

Проверьте Secure DNS / DNS-over-HTTPS.

Если браузер отправляет DNS напрямую внешнему DoH-провайдеру, Windows NRPT может не участвовать в разрешении имени.

Также проверьте, не перехватывает ли DNS другой VPN или security product.

## Discord открывается, но голос не работает

Частая причина — второй packet filter.

Временно остановите:

- другой zapret-клиент;
- VPN с packet filtering;
- программу, которая отдельно использует WinDivert.

После этого перезапустите Просвет и повторите проверку.

## Telegram не загружает медиа

Убедитесь, что:

1. Просвет включён;
2. Telegram выбран в списке сервисов;
3. нажата кнопка **«Подключить Telegram Desktop»**;
4. Telegram принял локальный proxy.

После изменения локального порта/секрета proxy нужно подключить заново.

## Антивирус ругается на WinDivert

Не отключайте защиту вслепую.

Сделайте три вещи:

1. убедитесь, что сборка скачана из официального GitHub Release;
2. сверьте SHA-256;
3. сохраните точное название детекта.

Если считаете предупреждение ложным, приложите название продукта/детекта к issue. Не загружайте приватные файлы и логи целиком без необходимости.

## После сбоя остались сетевые правила

Перезапустите Просвет с требуемыми правами: startup cleanup должен удалить собственные NRPT leftovers.

Проверить оставшиеся правила можно в PowerShell:

```powershell
Get-DnsClientNrptRule | Where-Object { $_.Comment -eq 'Prosvet' }
```

После штатного OFF собственных правил Просвета быть не должно.

## Просвет не запускается повторно

Приложение намеренно допускает только один системный экземпляр.

Проверьте tray: существующее окно может быть скрыто.

Если процесса визуально нет, но запуск не удаётся, приложите журнал и точное сообщение об ошибке.

## Где журнал

В приложении:

**Настройки → О программе → Журнал**

На диске:

```text
%LOCALAPPDATA%\Prosvet\prosvet.log
```

## Что приложить к issue

Минимальный полезный набор:

- версия Просвета;
- Windows 10/11 и номер сборки;
- провайдер и тип сети;
- сервис;
- ожидаемое и фактическое поведение;
- воспроизводится ли после перезапуска;
- последние релевантные строки журнала;
- точное сообщение антивируса, если оно есть.

Не публикуйте:

- пароли;
- cookies;
- auth tokens;
- содержимое аккаунтов;
- точный домашний адрес;
- полный журнал, если в нём есть лишние приватные данные.
