# Troubleshooting

## Сервис отмечен красным

Откройте **Настройки → Сеть → Проверить сервисы**.

Для DPI-сервисов повторные probes также дают механизму возможность перейти к следующей стратегии.

## Smart DNS-сервис открывается как раньше

Некоторые браузеры используют собственный DNS-over-HTTPS и обходят Windows NRPT.

Для диагностики временно отключите «Безопасный DNS» / Secure DNS в браузере и повторите проверку. После диагностики можно вернуть настройку и решить, какой DNS path нужен именно вашему браузеру.

## Другой VPN или zapret уже запущен

Два перехватчика трафика могут конфликтовать.

Для диагностики выключите второй VPN/zapret/packet filter, перезапустите Просвет и повторите проверку.

## Telegram

После первого включения Telegram mechanism нажмите **Подключить Telegram Desktop**.

Если порт 1443 уже занят, Просвет должен показать ошибку и откатить уже применённые изменения. Проверьте, какой процесс слушает порт:

```powershell
Get-NetTCPConnection -LocalPort 1443 -ErrorAction SilentlyContinue
```

## WinDivert и антивирус

Не отключайте защиту вслепую.

1. Убедитесь, что сборка скачана из GitHub Releases этого репозитория.
2. Сверьте SHA-256 с `SHA256SUMS.txt`.
3. Зафиксируйте точное название детекта и версию антивируса.
4. Если предупреждение остаётся, приложите эти данные к bug report.

## Проверить, остались ли NRPT-правила

После штатного выключения команда не должна возвращать правил Просвета:

```powershell
Get-DnsClientNrptRule | Where-Object { $_.Comment -eq 'Prosvet' }
```

## Лог

**Настройки → О программе → Журнал** открывает локальный `prosvet.log`.

Перед публикацией лога проверьте, что в нём нет данных, которыми вы не хотите делиться.
