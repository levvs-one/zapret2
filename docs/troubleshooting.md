# Диагностика

## Сервис отмечен красным

Откройте **Настройки → Сеть → Проверить сервисы**. Для DPI-сервисов повторная проверка позволяет движку перейти к следующей стратегии.

## AI-сервис всё ещё пишет про страну

Smart DNS меняет сетевой маршрут только для доменов сервиса. Регион аккаунта, платёжный профиль и номер телефона он не меняет.

Если сайт вообще не открывается в браузере, проверьте DNS-over-HTTPS / «Безопасный DNS»: браузер может обходить Windows NRPT.

## Discord открывается, но голос не работает

Убедитесь, что не запущен второй zapret/WinDivert-клиент или VPN с собственным packet filter. Два перехватчика часто конфликтуют.

## Telegram не загружает медиа

zapret2 должен быть включён, Telegram — выбран, а локальный proxy подключён через кнопку **Подключить Telegram Desktop**. После смены порта/секрета подключите proxy заново.

## Антивирус ругается на WinDivert

Не отключайте защиту вслепую. Скачивайте только GitHub Release, сверяйте `SHA256SUMS.txt` и приложите точное имя детекта к issue.

## После сбоя остались правила

Перезапустите zapret2 от администратора: startup cleanup удаляет собственные NRPT leftovers. Если это не помогло, приложите журнал из **Настройки → О программе → Журнал**.

## Что приложить к issue

- версию zapret2;
- Windows 10/11 и номер сборки;
- провайдера/тип сети;
- какой сервис не работает;
- журнал;
- точное сообщение антивируса, если оно есть.

Не публикуйте токены, cookies, пароли и содержимое аккаунтов.
