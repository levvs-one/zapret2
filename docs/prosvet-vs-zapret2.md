# Просвет и zapret2: в чём разница

Короткий ответ:

> **zapret2 — инструмент и движок. Просвет — готовое приложение для конкретных Windows-сценариев.**

Просвет не пытается заменить zapret2 и не является его «улучшенной версией». Для DPI-сервисов он использует zapret2 как один из backend-компонентов.

## Что такое zapret2

zapret2 — низкоуровневый anti-DPI проект с гибкими стратегиями обработки трафика.

Он полезен, когда нужно:

- самостоятельно подбирать и писать стратегии;
- работать с произвольными hostlist;
- настраивать фильтры и Lua;
- использовать Linux / OpenWRT / BSD / Windows;
- строить собственную сетевую конфигурацию;
- иметь максимум контроля над механизмом обхода DPI.

Эта гибкость — его сильная сторона.

## Что добавляет Просвет

Просвет ограничивает задачу до понятного пользовательского продукта на Windows.

### 1. UI вместо ручной конфигурации

Пользователь выбирает сервисы и нажимает одну кнопку.

Приложение само формирует нужный lifecycle вокруг backend-механизмов.

### 2. Автоматизация DPI-стратегий

Для поддерживаемых DPI-сервисов Просвет:

- запускает zapret2 с подготовленными стратегиями;
- проверяет доступность;
- при проблеме может переходить к следующей стратегии;
- запоминает рабочий вариант отдельно для конкретной сети.

Это не заменяет полный blockcheck / ручной tuning для нестандартных случаев, но убирает его из обычного пользовательского flow.

### 3. Не только DPI

Обычный zapret2 решает задачу DPI.

Просвет дополнительно включает:

- Windows NRPT + Smart DNS для сервисов с региональными ограничениями;
- локальный MTProto-over-WebSocket proxy для Telegram Desktop.

То есть одна оболочка управляет несколькими разными механизмами.

### 4. Windows lifecycle

Просвет берёт на себя то, что в ручной конфигурации обычно остаётся на пользователе или сторонней обвязке:

- single-instance;
- tray;
- autostart;
- запуск и остановку дочерних процессов;
- cleanup NRPT;
- cleanup после crash;
- installer / uninstaller;
- журнал и diagnostics.

### 5. Ограниченная поверхность

Просвет намеренно не показывает сотни параметров zapret2.

Это плюс для обычного пользователя и минус для человека, которому нужен полный контроль.

## Сравнение

| Возможность | Просвет | zapret2 напрямую |
| --- | --- | --- |
| Windows GUI | да | не является основной целью |
| One-click flow | да | нет, требуется конфигурация |
| Готовые поддерживаемые сервисы | да | пользователь задаёт сам |
| Автоматическая память DPI-стратегии | да, для поддерживаемых сценариев | пользовательская конфигурация |
| Smart DNS | да | нет |
| Telegram local proxy | да | нет |
| Tray / autostart | да | внешняя обвязка |
| Installer / uninstall cleanup | да | внешняя обвязка |
| Собственные Lua/hostlist/filters | ограниченно | да |
| OpenWRT / Linux / BSD | нет | да |
| Максимальная гибкость | нет | да |

## Когда выбирать Просвет

Выбирайте Просвет, если:

- у вас Windows 10/11;
- нужны поддерживаемые сервисы;
- вы не хотите разбираться в фильтрах, hostlist и Lua;
- хотите включать/выключать сервисы отдельно;
- важен нормальный uninstall и cleanup.

## Когда выбирать zapret2 напрямую

Используйте zapret2 напрямую, если:

- нужен роутер / OpenWRT;
- нужен Linux/BSD;
- нужны свои hostlist;
- вы хотите экспериментировать со стратегиями;
- нужен сервис, которого нет в каталоге Просвета;
- стандартная логика Просвета не подходит вашему провайдеру;
- нужен полный контроль над packet filtering.

## Почему проект называется zapret2 в URL репозитория

Репозиторий исторически создавался вокруг zapret2-интеграции, но пользовательский продукт называется **Просвет**.

С точки зрения продукта правильная модель такая:

```text
Просвет
├─ zapret2       → DPI
├─ Smart DNS     → regional access
└─ Telegram proxy → Telegram Desktop
```

То есть zapret2 — важный backend, но уже не весь продукт.
