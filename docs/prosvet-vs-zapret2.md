# Просвет и zapret2: в чём разница

## Коротко

**zapret2 — anti-DPI engine и набор низкоуровневых инструментов. Просвет — готовое Windows-приложение для ограниченного набора пользовательских сценариев, где zapret2 является одним из backend-компонентов.**

Просвет не является «новой версией zapret2», не форкает его философию и не пытается заменить raw-конфигурацию.

## Модель проекта

```text
Просвет
├─ zapret2 / WinDivert   → DPI-сценарии
├─ Windows NRPT          → Smart DNS для выбранных доменов
└─ Telegram proxy        → Telegram Desktop
```

Из-за этого сравнивать проекты как две версии одного инструмента не совсем правильно: они находятся на разных уровнях абстракции.

## Что даёт zapret2

zapret2 полезен, когда нужен прямой контроль:

- свои hostlist;
- свои фильтры;
- Lua и ручная настройка стратегий;
- экспериментирование с packet manipulation;
- Linux / OpenWRT / BSD / Windows;
- нестандартные сценарии, которых нет в каталоге Просвета.

Это сильная сторона zapret2: он предоставляет механизм и не навязывает продуктовый workflow.

## Что добавляет Просвет

### Готовый Windows lifecycle

Просвет берёт на себя:

- single-instance;
- tray;
- autostart;
- запуск и остановку дочерних процессов;
- cleanup NRPT;
- cleanup после crash;
- installer / uninstaller;
- локальный журнал;
- health checks;
- системный rollback при ошибках.

Пользователь не должен вручную собирать это вокруг движка.

### Каталог поддерживаемых сервисов

Вместо произвольной конфигурации пользователь включает конкретные сервисы.

Для каждого сервиса заранее определены механизм, домены и пользовательский flow.

### Автоматизация DPI-стратегий

Для поддерживаемых DPI-сценариев Просвет:

- формирует аргументы zapret2;
- запускает engine;
- проверяет доступность;
- может перейти к следующей подготовленной стратегии;
- запоминает рабочий вариант для конкретной сети.

Это не заменяет ручной blockcheck для сложной сети, но снимает его с обычного пользователя.

### Механизмы за пределами DPI

Некоторые проблемы вообще не являются DPI-проблемами.

Поэтому Просвет также использует:

- Windows NRPT + Smart DNS для выбранных регионально ограниченных сервисов;
- локальный MTProto-over-WebSocket proxy для Telegram Desktop.

## Сравнение

| Возможность | Просвет | zapret2 напрямую |
| --- | --- | --- |
| Основная роль | готовый Windows-клиент | anti-DPI engine/toolkit |
| Windows GUI | **Да** | не основная цель |
| One-click start/stop | **Да** | конфигурация пользователя |
| Готовый каталог сервисов | **Да** | пользователь задаёт сам |
| Память стратегии по сети | **Да** | ручная/внешняя логика |
| Health checks | **Да** | внешняя логика |
| Smart DNS | **Да** | нет |
| Telegram local proxy | **Да** | нет |
| Tray/autostart/single-instance | **Да** | внешняя обвязка |
| Installer и uninstall cleanup | **Да** | внешняя обвязка |
| Произвольные Lua/filters/hostlists | ограниченно | **Да** |
| Linux/OpenWRT/BSD | нет | **Да** |
| Максимальная гибкость | нет | **Да** |
| Минимум решений для пользователя | **Да** | нет |

## Когда выбирать Просвет

Просвет подходит, если:

- используется Windows 10/11;
- нужны сервисы из встроенного каталога;
- не хочется вручную настраивать hostlist, filters и Lua;
- нужен предсказуемый start/stop;
- важны tray, autostart, diagnostics и корректный uninstall;
- нужен единый UI для DPI, Smart DNS и Telegram.

## Когда выбирать zapret2 напрямую

zapret2 лучше, если:

- нужен OpenWRT, Linux или BSD;
- нужны собственные hostlist;
- требуется тонкая ручная настройка;
- вы исследуете стратегии;
- нужен сервис/протокол вне каталога Просвета;
- автоматические стратегии Просвета не подходят сети;
- нужен полный контроль над фильтрацией.

## Что Просвет намеренно не делает

Просвет не пытается быть GUI для каждого параметра zapret2.

Если вынести в интерфейс сотни низкоуровневых опций, проект потеряет главный смысл: **ограниченный, понятный и восстанавливаемый пользовательский lifecycle**.

## Почему репозиторий называется `zapret2`

Это историческое имя репозитория: проект начинался как Windows-обвязка вокруг zapret2.

Пользовательский продукт называется **Просвет**. В текущей архитектуре zapret2 остаётся важной частью, но не определяет весь продукт.
