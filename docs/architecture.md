# Архитектура

Просвет — небольшой Windows-клиент вокруг нескольких независимых сетевых механизмов. Главный принцип: **не превращать один способ обхода в глобальный туннель для всего трафика**.

## Поток управления

```text
UI
 └─ Controller
    ├─ DPI        → winws2 / WinDivert
    ├─ Smart DNS  → Windows NRPT
    └─ Telegram   → локальный MTProto-over-WebSocket proxy
```

`Controller` — единственный источник состояния для UI. Все системные мутации сериализуются: start, stop и изменение сервисов не должны выполняться одновременно.

## Инварианты lifecycle

1. Два системных изменения не выполняются параллельно.
2. `stop()` является барьером: после его завершения cleanup закончен.
3. Ошибка дочернего процесса переводит приложение через единый shutdown path.
4. После crash leftovers NRPT очищаются на следующем запуске.
5. Один экземпляр приложения управляет системным состоянием.
6. Выключенный механизм не оставляет собственный процесс или правило активным.

Эти свойства важнее визуального состояния кнопки. UI отражает backend, а не наоборот.

## Компоненты

### `lib/src/core`

Состояние приложения, настройки, probes и Windows backend. Здесь не должно быть Flutter-виджетов.

### `lib/src/engine/zapret`

Формирует аргументы `winws2`, хранит стратегии и управляет процессом. CI проверяет собранную командную строку парсером самого zapret2.

### `lib/src/engine/smartdns`

Создаёт/удаляет NRPT-правила только для доменов выбранных сервисов и выполняет DNS-проверки.

### `lib/src/engine/telegram`

Локальный MTProto proxy поверх WebSocket. Реализация не требует отдельного внешнего proxy-сервера.

### `lib/src/ui`

Тонкий Material 3 desktop UI. В нём нет прямых PowerShell/Process вызовов к сетевому движку.

### `engine`

Версионируемая интеграция с zapret2: Lua, доменные списки и WinDivert-фрагменты. Бинарники движка не принимаются на веру: `tools/fetch-engine.ps1` скачивает фиксированную версию и проверяет SHA-256.

## Release path

```text
format → analyze → tests → zapret parser dry-run
                         ↓
               Windows release build
                         ↓
             installer install/uninstall
                         ↓
             portable ZIP + Setup.exe
                         ↓
                  SHA256SUMS.txt
```

Релиз создаётся только из `main` для версии из `VERSION`. Повторный push с уже опубликованной версией не создаёт новый релиз.
