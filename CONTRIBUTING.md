# Contributing

Главный приоритет Просвета — предсказуемый Windows lifecycle. Новая функция не должна оставлять систему в неожиданном состоянии после stop, crash или uninstall.

## Инварианты

Изменение не должно ломать следующие свойства:

1. системные mutations выполняются последовательно;
2. OFF означает отсутствие активного winws2, локального proxy и NRPT-правил Просвета;
3. аварийное завершение GUI не оставляет дочерний winws2 жить отдельно;
4. повторный запуск не создаёт второй системный экземпляр;
5. сохранённые пользовательские настройки не перезаписываются «для удобства» после ошибки чтения;
6. изменение списка стратегий не должно молча перенумеровывать уже сохранённые стратегии.

## Перед PR

```bash
flutter pub get
dart format --output=none --set-exit-if-changed lib test tool tools
flutter analyze
flutter test
tools/verify-engine-args.sh
```

Интерфейс без системных изменений:

```bash
flutter run -d windows -- --demo
```

## Изменения сервисов

Каталог находится в `lib/src/catalog/services.dart`.

Для нового сервиса укажите:

- механизм;
- домены, если используется Smart DNS;
- короткий пользовательский caption;
- способ ручной проверки.

DPI-списки находятся в `engine/lists/`.

## Изменения zapret2-стратегий

Стратегии находятся в `lib/src/engine/zapret/strategies.dart`.

Добавляйте новую стратегию в конец списка, если только миграция старых сохранённых индексов не реализована явно. В PR укажите, на каком подключении и сервисе проверялось изменение.

## Release-sensitive изменения

Если меняются installer, autostart, NRPT, process lifecycle, Windows runner или packaging, прочитайте [docs/release.md](docs/release.md) и выполните ручной Windows smoke-check перед тегом.

PR template просит отдельно описать пользовательское изменение, затронутый invariant и способ проверки.
