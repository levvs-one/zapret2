# Конфиденциальность

`zapret2` не собирает телеметрию, не требует аккаунта и не отправляет настройки разработчику.

## Локальное состояние

Для совместимости с версиями 0.1–0.2 данные пока хранятся в legacy namespace `%LOCALAPPDATA%\\Prosvet`:

- `settings.json` — выбранные сервисы, параметры запуска и secret локального Telegram proxy;
- память выбранных DPI-стратегий для разных сетей;
- `prosvet.log` — технический диагностический журнал.

Смена публичного имени на `zapret2` не мигрирует и не дублирует эти данные.

## Сетевой трафик

В сеть уходят только данные, необходимые выбранным механизмам:

- обычный трафик сервисов, которыми вы пользуетесь;
- DNS-запросы Smart DNS — только для доменов включённых сервисов;
- короткие HTTPS/DNS probes при проверке доступности;
- Telegram traffic при включённом локальном Telegram proxy.

`zapret2` не расшифровывает HTTPS и не устанавливает собственный root certificate.

При удалении Setup очищает приложение, задачу автозапуска, собственные NRPT rules и legacy local state.
