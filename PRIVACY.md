# Конфиденциальность

Просвет не собирает телеметрию, не требует аккаунта и не отправляет настройки разработчику.

Что приложение хранит локально в `%LOCALAPPDATA%\Prosvet`:

- `settings.json` — включённые сервисы, настройки запуска и секрет локального Telegram-прокси;
- память выбранных zapret2-стратегий для разных сетей;
- `prosvet.log` — технический журнал для диагностики.

Что уходит в сеть:

- обычный трафик сервисов, которыми вы пользуетесь;
- DNS-запросы выбранных Smart DNS-сервисов — только для доменов, перечисленных в каталоге Просвета;
- короткие HTTPS/DNS-проверки доступности, когда Просвет проверяет состояние сервисов;
- Telegram-трафик при включённом локальном Telegram-прокси.

Просвет не расшифровывает HTTPS-трафик и не устанавливает собственные корневые сертификаты.

При удалении через Setup удаляются программа, задача автозапуска, NRPT-правила Просвета и локальные данные из `%LOCALAPPDATA%\Prosvet`.
