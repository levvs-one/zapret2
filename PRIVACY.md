# Privacy

Просвет не требует аккаунта, не содержит собственной телеметрии и не отправляет настройки разработчику.

## Локальные данные

В `%LOCALAPPDATA%\Prosvet` могут храниться:

- `settings.json` — включённые сервисы, настройки запуска и secret локального Telegram-прокси;
- выбранные zapret2-стратегии для разных сетей;
- `prosvet.log` — локальный диагностический журнал.

## Сетевые обращения

Приложение может выполнять:

- обычные соединения к выбранным пользователем сервисам;
- DNS-запросы через выбранный Smart DNS только для доменов из каталога Просвета;
- короткие проверки доступности сервисов;
- Telegram-трафик через локальный proxy, когда этот механизм включён.

Просвет не устанавливает root CA и не расшифровывает HTTPS.

При uninstall удаляются задача автозапуска, NRPT-правила Просвета и локальная папка `%LOCALAPPDATA%\Prosvet`.
